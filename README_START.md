# 遊戲啟動指南

## 啟動服務器

1. 確保已安裝 Node.js 和 npm
2. 安裝依賴（如果尚未安裝）：
   ```bash
   npm install
   ```

3. 啟動服務器：
   ```bash
   npm start
   ```
   或
   ```bash
   node server.js
   ```

4. 服務器將在 `http://localhost:3000` 上運行

## 遊戲流程

1. 打開瀏覽器，訪問 `http://localhost:3000`
2. 註冊或登錄帳號
3. 創建或加入房間
4. 等待兩個玩家都準備好
5. 點擊 "Start Game" 開始遊戲
6. 享受遊戲！

## 遊戲控制

- **方向鍵左/右**: 移動
- **方向鍵上**: 跳躍（支持雙重跳躍）
- **方向鍵下**: 
  - 在平台上：穿過平台
  - 在空中：快速下降
- **Z 鍵**: 射擊

## 功能特性

- ✅ 多平台跳躍系統
- ✅ 雙重跳躍
- ✅ 快速下降
- ✅ 穿過平台（按下下鍵）
- ✅ 多人對戰
- ✅ 武器系統
- ✅ 道具系統

## 故障排除

如果遇到問題：

1. 確保服務器正在運行
2. 檢查瀏覽器控制台是否有錯誤
3. 確保兩個玩家都已連接到同一個房間
4. 檢查網絡連接
